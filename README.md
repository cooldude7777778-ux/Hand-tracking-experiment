# MATRIX//HANDLINK AR

Киберпанк PWA: трекинг рук (MediaPipe Hands) + Matrix-кубы (Three.js) поверх веб-камеры. Звук синтезируется через Web Audio API.

## Жесты
- **▲ Треугольник** (большой + указательный + средний вместе) — куб в центре жеста, размер зависит от разведения пальцев, при размыкании распадается с глитчем.
- **☝ Мизинец** (остальные поджаты) — спавн постоянного куба; опустил мизинец — куб застыл в 3D.
- **◆ Щепотка** (большой + указательный) у куба — захват и перенос.

## Запуск
Камера работает только по **HTTPS** или `localhost`:
```bash
python3 -m http.server 8080   # затем открыть http://localhost:8080
```
**GitHub Pages:** Settings → Pages → Deploy from branch → `main` / root. Откройте ссылку на телефоне и нажмите «Установить / На экран Домой».
